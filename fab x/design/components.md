# Component Direction

## Core Components
- Buttons: primary, secondary, ghost
- Cards: feature, service, portfolio, testimonial
- Navigation: sticky top nav with subtle scroll response
- Containers: wide editorial layout with generous spacing
- Footer: lightweight, minimalist, conversion-friendly

## Visual Principles
- Rounded but refined forms
- Strong hierarchy and spacing rhythm
- Motion should support readability, not distract
- Components should feel premium even in dark mode
