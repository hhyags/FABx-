# Foundation Prompt

Create a production-ready Next.js 15 project with App Router, TypeScript, Tailwind CSS, shadcn/ui, React Three Fiber, Drei, GSAP, Framer Motion, Lenis, ESLint, and Prettier.

Configure a scalable folder structure, a dark theme, typography tokens, design tokens, and reusable layouts. Do not create pages yet. If anything is unclear or cannot be completed, stop and ask before proceeding.

## Project Goals
- Build a strong technical foundation for a cinematic, editorial experience
- Prepare the application for future section-by-section implementation
- Keep the architecture scalable and maintainable
